Fika Nova

Identidade / Logotipos

Uma escola de surf.

Mais do que uma escola, a Fika Nova busca se situar no mundo do surf como uma marca de valor, com a qual o público alvo se identifique e valorize. Situada na Costa Rica, na praia de Tamarindo, com ótimo perfil para o surf, a marca já nasce para ser não só uma escola, mas também pronta para iniciar-se no e-commerce de vestuário para os amantes do surf.

  • Cliente Fernando Castillo
  • Trabalho Logotipo, Identidade visual, T-shirt
  • Segmento Escola de Surf.
